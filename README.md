# New Life Congregation CMS

Church management application for **New Life Congregation**, Presbyterian Church of Ghana — Ga West Presbytery.

## Requirements

- Node.js 20 or newer
- Supabase project credentials

## Setup

1. Add the Supabase project URL and anon key to the root `.env` file.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.
4. Run a production check with `npm run build`.

The database schema and row-level security policies are managed in Supabase. Do not add schema changes through this frontend project.
